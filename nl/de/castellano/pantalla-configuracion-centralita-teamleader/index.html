    Quick Backup TL Configuration¶

    Change only the options you need. For a first test, use an empty folder, keep 0 days and leave full backup disabled.

    { loading=lazy }

    Main fields¶

    Field or option What it does When to use
    Destination folder (--destino) Saves the backup files. The initial path is C:\backup_teamleader if none is saved. Every run. Use a folder with write permissions and sufficient space.
    Rollback days (--restday) Subtracts days from the date from which changes are searched. When you need to review changes from earlier days. Use 0 under normal conditions.
    Full re-run backup (--full) Queries complete information instead of limited to subsequent changes. To rebuild the backup or correct a history that is not reliable. May take longer.
    Download attachments - key Enables attachment download when a key is entered. Only if you need to keep documents and have additional space.
    Export to Excel - destination folder Converts .encrypted files from the backup folder to .json in another folder. When you need readable data. The interface name "Excel" does not imply .xlsx generation.

    Recommended configuration by goal¶

    Goal Days Complete Attachments
    First test 0 No No
    Normal incremental backup 0 No As needed
    Recover recent changes Number of days to look back No As needed
    Rebuild entire set 0 Yes As needed

    Conversion is separate

    First create the backup. Then choose an output folder and click Export. The application requests the Client Secret to confirm the conversion.
