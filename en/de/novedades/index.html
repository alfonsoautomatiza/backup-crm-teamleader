    Changelog¶

    Version history of published Backup Teamleader releases.

    0.1.2 — 2026-08-16¶

    First complete public version.

    Improvements¶

    • New application icon with Teamleader's visual identity, applied to the executable, installer and manual.
    • Identifiable installer: the GitHub Releases download is now called backuptl-0.1.2-win-x64-stable.zip (previously dist.zip), with version, platform and channel in the name.
    • Official installation available on Microsoft Store (see Install).

    Fixes¶

    • The application no longer fails when started offline or without configured credentials.
    • Removed the double license request on each backup.
    • The --destino option is now respected in JSON mode (-j).
    • Fixed timeouts and browser opening after authentication.
    • config.ini encryption: the API secret is no longer empty when saving configuration.
    • Comprehensive project quality review (7 fixes).
