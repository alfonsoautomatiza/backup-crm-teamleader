    Resolver problemas de Backup Teamleader¶

    Lea el estado final y el mensaje completo antes de repetir una copia. Reintentar sin corregir la causa puede mezclar una ejecución parcial con la siguiente.

    flowchart TD
    P["La copia falla o no genera archivos"] --> Q1{"¿La aplicación abre?"}
    Q1 -- No --> A1["Cierre la instancia previa y revise backupTL_crash.log"]
    Q1 -- Sí --> Q2{"¿Pide credenciales?"}
    Q2 -- Sí --> A2["Complete Client ID y Client Secret y pulse Verificar"]
    Q2 -- No --> Q3{"¿Errores en el estado final?"}
    Q3 -- Sí --> A3["Corrija el primer error y conserve el registro"]
    Q3 -- No --> A4["Pruebe con una carpeta local vacía y sin adjuntos"]

    Diagnóstico rápido¶

    Problema Comprobación Acción
    La aplicación no abre Confirme que no existe otra instancia en ejecución. Cierre la instancia anterior y vuelva a abrir. Si hubo un fallo de inicio, busque backupTL_crash.log junto al ejecutable.
    Se solicitan credenciales Compruebe que ambos campos están completos. Revise Credenciales de Teamleader y pulse Verificar una sola vez.
    La carpeta no existe Revise la ruta mostrada en Carpeta destino. Elija una carpeta válida o permita que la aplicación cree la ruta configurada.
    No se generan archivos Compruebe permisos, espacio libre, estado final y mensajes de la consola integrada. Pruebe con una carpeta local vacía y sin adjuntos.
    La copia termina con errores Lea el primer error y conserve el registro. Corrija esa causa antes de ejecutar de nuevo.
    La aplicación indica una copia previa inconclusa Existe una marca de ejecución anterior. Use Relanzar solo después de confirmar que no queda otro proceso activo.
    Detener no finaliza de inmediato La cancelación es una solicitud al proceso en curso. Espere hasta que el estado muestre Cancelado.
    No aparecen adjuntos Compruebe la clave, el espacio libre y los mensajes del proceso. Repita primero una copia sin adjuntos para separar ambos problemas.
    “Exportar” no crea un .xlsx La implementación actual convierte los archivos a .json. Busque los .json en la carpeta elegida para la exportación.

    Recoger evidencia segura¶

    Antes de solicitar soporte, reúna:

    • versión instalada y origen de instalación;
    • fecha y hora aproximadas del fallo;
    • carpeta de destino utilizada;
    • primer mensaje de error completo;
    • estado final mostrado por la aplicación;
    • registro de ejecución o backupTL_crash.log, si existe.

    Elimine datos sensibles

    Oculte Client ID, Client Secret, tokens, nombres de clientes, correos, teléfonos, rutas personales y contenido exportado antes de compartir capturas o registros.

    Recuperación segura¶

    1. Detenga cualquier instancia activa.
    2. Conserve la carpeta que contiene el resultado parcial; no la borre todavía.
    3. Cree una carpeta vacía para una prueba controlada.
    4. Ejecute sin adjuntos, sin conversión y con Backup rehacer completo desactivado.
    5. Si la prueba funciona, active de nuevo las opciones una por una.

    Siguiente paso¶

    Cuando la prueba básica termine correctamente, vuelva a Configurar las opciones de copia.
