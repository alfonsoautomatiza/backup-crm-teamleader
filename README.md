# Backup Teamleader

## Español

Backup Teamleader es una herramienta para realizar copias de seguridad de datos de Teamleader. La documentación principal explica cómo abrir la aplicación, preparar la carpeta destino, ejecutar la copia, usar opciones de consola y revisar los archivos generados.

## English

Backup Teamleader is a tool for creating backups of Teamleader data. The main documentation explains how to open the application, prepare the destination folder, run the backup, use console options, and review the generated files.

## Français

Backup Teamleader est un outil permettant de créer des copies de sécurité des données Teamleader. La documentation principale explique comment ouvrir l'application, préparer le dossier de destination, lancer la copie, utiliser les options en console et vérifier les fichiers générés.

## Instalación

### Microsoft Store

Instale Backup Teamleader desde la
[Microsoft Store](https://apps.microsoft.com/detail/9PCPJC5262SQ) para recibir
actualizaciones automáticas en Windows.

### GitHub Releases

La versión publicada también se distribuye desde
[GitHub Releases](https://github.com/alfonsoautomatiza/backup-crm-teamleader/releases).
Cada release identifica su versión (`backuptl-<versión>-win-x64-stable.zip`)
para instalación o ejecución manual.

Compruebe el número de versión y descargue los archivos únicamente desde el
repositorio oficial. Una instalación obtenida desde GitHub Releases no recibe
actualizaciones automáticas de Microsoft Store.
