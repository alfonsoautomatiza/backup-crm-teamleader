    Configurar Backup TL antes de usarlo

    La configuración de Backup TL reúne los datos que permiten conectar con Teamleader y adaptar el uso diario de la herramienta. Revísela antes de hacer pruebas con llamadas, búsquedas de teléfonos o creación de nuevas fichas.

    Camino rápido

    1. Abra la pantalla de configuración de Backup TL.
    2. Seleccione el idioma de la aplicación.
    3. Introduzca las credenciales obtenidas desde API Teamleader.
    4. Ajuste el tiempo de cierre automático para pantallas de alta o consulta.
    5. Active el enlace con Android solo si va a usar App Call Remoto.

    Detalles

    Parámetro Para qué sirve
    Idioma Define el idioma visible de la aplicación.
    Claves API Permiten conectar Backup TL con Teamleader.
    Cierre automático Evita que una pantalla de alta quede abierta por falta de actividad.
    Enlace móvil Android Permite trabajar con llamadas entrantes o salientes cuando App Call Remoto está instalado y conectado.
    Campos libres Puede relacionar campos libres de Teamleader con datos localizados durante el alta de una empresa, si su configuración lo contempla.

    Checklist

    • Ha seleccionado el idioma correcto.
    • Ha pegado el Client ID y el Client secret de Teamleader.
    • Ha definido un tiempo de cierre automático adecuado para su flujo de trabajo.
    • Ha activado Android únicamente si lo va a usar.
    • Ha guardado la configuración antes de hacer la primera prueba.

    Siguiente paso

    Vuelva a la guía de uso y realice una primera consulta con un número de teléfono conocido.
