    Realizar una copia de seguridad de Teamleader con Backup TL

    Backup TL permite generar copias de seguridad de datos de Teamleader desde una ventana gráfica o desde un modo de consola/ejecutable. Esta guía está pensada para un usuario con criterio técnico: explica qué preparar, qué revisar antes de ejecutar, cómo interpretar el resultado y qué evidencias conviene conservar.

    Note

    Las capturas de esta página están planificadas. Guarde cada imagen en docs/img/ con el nombre indicado en el checklist de capturas. Mientras no existan los archivos, las referencias sirven como guía exacta de producción visual.

    Backup TL puede convivir con productos externos conectados al entorno de trabajo, como App Call Remoto. Ese producto es opcional y no forma parte del flujo principal de copia de seguridad descrito aquí.

    Camino rápido

    1. Instale Backup TL desde Microsoft Store, o use una versión manual publicada en GitHub Releases si la Store no está disponible.
    2. Abra Backup TL desde el acceso directo instalado o desde el ejecutable correspondiente.
    3. Complete la ventana de credenciales si la herramienta la muestra.
    4. Seleccione la carpeta destino donde se guardará la copia.
    5. Decida si necesita copia completa, adjuntos, exportación a Excel o recuperar cambios de días anteriores.
    6. Ejecute la copia y supervise el estado hasta el mensaje de finalización.
    7. Revise la carpeta destino, los archivos generados y el registro de ejecución si necesita trazabilidad técnica.

    Tip

    Para una primera prueba, use una carpeta destino vacía y fácil de identificar. Así podrá distinguir claramente qué archivos creó Backup TL durante esa ejecución.

    Flujo operativo

    flowchart TD
    A[Instalar o abrir Backup TL] --> B{La herramienta solicita credenciales?}

    Instalación y apertura

    Opción Cuándo usarla Qué debe comprobar
    Microsoft Store Ruta recomendada para usuarios finales. La aplicación queda instalada, firmada y disponible desde el acceso directo de Windows.
    GitHub Releases Alternativa manual cuando no pueda usar Microsoft Store o necesite una versión concreta. Puede aparecer una advertencia de SmartScreen y las actualizaciones no serán automáticas.
    Modo consola/ejecutable Uso técnico, automatizado o supervisado desde una terminal. Debe abrir la herramienta con el ejecutable distribuido y revisar la salida de estado.

    Warning

    Use GitHub Releases solo si tiene una razón concreta para no instalar desde Microsoft Store. La Store es la vía recomendada porque reduce bloqueos de seguridad y simplifica actualizaciones.

    Preparar credenciales

    Al iniciar o ejecutar una copia, Backup TL puede mostrar una pantalla de credenciales. Complete los datos solicitados y continúe hasta que la herramienta confirme el acceso o permita seguir con la configuración.

    Revisión Criterio
    Datos visibles No documente ni comparta claves reales, tokens, contraseñas ni identificadores sensibles.
    Confirmación Espere a que la herramienta acepte las credenciales antes de iniciar la copia.
    Evidencia Si necesita una captura, oculte los valores y deje visibles solo etiquetas, campos y botones.

    Warning

    Las capturas de credenciales deben tomarse con valores ocultos, enmascarados o de prueba. No suba claves reales al repositorio ni a la documentación publicada.

    Configurar la copia

    Antes de pulsar el botón de ejecución, revise estos campos.

    Campo u opción Uso operativo Recomendación
    Carpeta destino Define dónde se guardarán los archivos generados. Use una ruta con permisos de escritura y suficiente espacio.
    Retroceder días Permite recuperar cambios anteriores. Mantenga 0 si no necesita ampliar el rango.
    Backup rehacer completo Fuerza una copia completa desde cero. Úselo cuando quiera reconstruir la copia o descartar una ejecución incremental.
    Descargar ficheros adjuntos Activa la descarga de adjuntos si introduce la clave correspondiente. Verifique antes que dispone de la clave y espacio en disco.
    Exportación a Excel Permite seleccionar una carpeta de salida para exportaciones. Confirme la carpeta y la clave solicitada antes de compartir archivos.

    Tip

    Si el objetivo es validar la herramienta, ejecute primero una copia sin adjuntos ni exportación a Excel. Después active opciones adicionales de una en una para aislar errores.

    Ejecutar y supervisar

    1. Pulse Ejecutar backup cuando la configuración esté lista.
    2. Observe la zona de consola o estado para comprobar el avance.
    3. Espere el mensaje de finalización antes de abrir o mover archivos generados.
    4. Use Detener solo si necesita cancelar la ejecución. Espere a que la herramienta confirme la solicitud de cancelación.

    Caution

    No cierre la aplicación ni mueva la carpeta destino mientras la copia está en curso. Puede dejar archivos incompletos o una ejecución difícil de auditar.

    Revisar resultados

    Al terminar, verifique el resultado antes de dar la copia por válida.

    Evidencia Qué revisar Dónde mirarlo
    Estado final Que la ejecución haya terminado correctamente o indique una cancelación controlada. Etiqueta de estado o consola integrada.
    Archivos generados Que existan archivos en la carpeta destino y que la fecha corresponda a la ejecución. Carpeta seleccionada en Carpeta destino.
    Adjuntos Que se hayan creado o actualizado los archivos esperados si activó la opción. Carpeta destino o subcarpetas generadas por la herramienta.
    Excel Que la exportación esté en la carpeta elegida y pueda abrirse. Carpeta configurada en Exportación a Excel.
    Registro Mensajes de error, avisos o confirmación detallada. Registro de ejecución generado por la herramienta.

    Uso por consola/ejecutable

    El modo consola/ejecutable sirve para usuarios técnicos que prefieren lanzar la copia fuera de la ventana principal o revisar mensajes de salida con más detalle.

    Necesidad Acción recomendada
    Copia básica Abra el ejecutable o acceso de consola distribuido con la aplicación y espere los mensajes de inicio y finalización.
    Cambiar carpeta destino Indique una carpeta destino válida desde las opciones del modo consola/ejecutable.
    Forzar copia completa Active la opción equivalente a Backup rehacer completo.
    Descargar adjuntos Use la opción de adjuntos e introduzca la clave requerida.
    Generar archivos legibles/exportables Use la opción de exportación que corresponda y proteja la clave utilizada.
    Revisar auditoría Consulte el registro de ejecución generado por la herramienta.

    Note

    Esta guía no publica comandos internos. Si opera en modo consola/ejecutable, use las instrucciones distribuidas con su paquete instalado o con la versión publicada que esté ejecutando.

    Solución de problemas básica

    Situación Qué revisar Evidencia útil
    No aparece la ventana gráfica Confirme que Backup TL está instalado y que se abrió desde el acceso directo o ejecutable correcto. Captura del acceso directo o del intento de apertura, sin datos sensibles.
    La aplicación solicita credenciales Complete los datos solicitados y espere confirmación. Captura con credenciales ocultas.
    No encuentra archivos generados Revise la carpeta configurada como destino y los permisos de escritura. Captura de carpeta destino y listado de archivos.
    La copia necesita rehacerse completa Active Backup rehacer completo antes de ejecutar. Captura de la opción marcada.
    Adjuntos o Excel no se generan Verifique clave, carpeta de salida y mensajes de estado. Captura de consola/estado y registro.
    Aparece un error Lea el mensaje completo y revise el registro antes de repetir. Captura del error sin claves, tokens ni datos personales.

    Checklist antes de usar Backup TL

    • Backup TL está instalado desde Microsoft Store o se dispone de una versión manual concreta.
    • Las credenciales necesarias están disponibles y se introducen solo en la herramienta.
    • La carpeta destino existe, tiene permisos de escritura y suficiente espacio.
    • Se decidió si la copia será incremental o completa.
    • Se decidió si se descargarán adjuntos.
    • Se decidió si se exportará a Excel.
    • Se revisará el estado final antes de cerrar la herramienta.
    • Se conservará el registro si la ejecución debe auditarse.
