    Instalar Backup TL

    La forma recomendada de instalar Backup TL es desde Microsoft Store. Use las descargas de GitHub Releases solo como alternativa manual cuando no pueda instalar desde la Store.

    Camino rápido

    1. Abra la página de Backup Teamleader en Microsoft Store.
    2. Instale la aplicación desde Microsoft Store.
    3. Abra Backup TL y siga la guía única de uso para preparar la primera copia de seguridad.

    Detalles

    Opción Cuándo usarla
    Microsoft Store Instalación recomendada. El paquete está firmado por Microsoft, se actualiza automáticamente y evita bloqueos habituales de SmartScreen.
    GitHub Releases Alternativa manual si necesita descargar un .msix o .zip de una versión concreta. Puede mostrar avisos de SmartScreen y no es la vía oficial de actualización.
