    Capturas necesarias para Backup TL¶

    Este listado define qué imágenes faltan para completar la documentación visual de Backup TL. Guarde todas las capturas en docs/img/ y use exactamente el nombre de archivo indicado.

    Proteja todos los datos

    No capture credenciales reales, claves, tokens, nombres de clientes, teléfonos, correos, rutas privadas ni datos personales. Si un dato debe aparecer para explicar la pantalla, use datos de prueba o aplique ocultación antes de guardar la imagen.

    Reglas de captura¶

    Regla Criterio
    Formato PNG.
    Ubicación docs/img/.
    Nombre Exactamente el valor de la columna Nombre de archivo esperado.
    Resolución Preferentemente ventana completa de la herramienta, sin recortar controles importantes.
    Privacidad Ocultar valores sensibles antes de guardar o publicar.
    Estado Mostrar una configuración comprensible, no pantallas a medio completar salvo que la captura documente un error.

    Orden recomendado de producción¶

    1. Capture primero instalación, pantalla principal y carpeta destino.
    2. Capture credenciales, adjuntos y conversión JSON con datos ficticios u ocultos.
    3. Ejecute una copia de prueba en carpeta temporal/controlada.
    4. Capture estado, resultados y un error controlado solo si aparece de forma segura.
    5. Revise cada imagen antes de subirla al repositorio.

    Referencias ya preparadas¶

    La guía principal ya contiene referencias a estas imágenes con rutas ../img/<nombre>.png. Cuando coloque los archivos en docs/img/, MkDocs los mostrará automáticamente.

    Tip

    Si una captura todavía no existe, no cambie el nombre en la documentación. Cree el archivo con el nombre planificado para mantener estable la referencia.
