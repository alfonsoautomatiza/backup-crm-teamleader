    Realizar una copia de seguridad de Teamleader con Backup TL¶

    Use esta guía para preparar una carpeta de destino, ejecutar una copia desde la ventana principal y comprobar el resultado. Para automatizar el proceso, consulte el uso desde la consola.

    flowchart LR
    A["Preparar credenciales"] --> B["Configurar la copia"]
    B --> C["Ejecutar backup"]
    C --> D["Supervisar el avance"]
    D --> E["Comprobar el resultado"]
    E --> F["Archivos .encriptado verificados"]

    Camino rápido¶

    1. Instale Backup Teamleader y abra la aplicación.
    2. Complete Client ID y Client Secret si aparece la ventana de credenciales.
    3. Elija una carpeta de destino vacía o dedicada a esta copia.
    4. Mantenga Retroceder días en 0 y Backup rehacer completo desactivado para una ejecución incremental normal.
    5. Pulse Ejecutar backup.
    6. Espere Proceso completado correctamente y revise los archivos .encriptado de la carpeta.

    Primera ejecución

    No active adjuntos ni conversión de archivos en la primera prueba. Añada cada opción por separado después de confirmar que la copia básica termina correctamente.

    Preparar credenciales¶

    Al iniciar, Backup Teamleader puede mostrar una ventana con los campos Client ID y Client Secret. Pulse Verificar después de completar ambos campos. La aplicación guarda los valores y continúa con la autorización; si no puede verificar en ese momento, muestra el detalle disponible.

    Revisión Criterio
    Datos visibles No documente ni comparta claves reales, tokens, contraseñas ni identificadores sensibles.
    Confirmación Espere a que la herramienta acepte las credenciales antes de iniciar la copia.
    Evidencia Si necesita una captura, oculte los valores y deje visibles solo etiquetas, campos y botones.

    Proteja las credenciales

    No comparta capturas, archivos de configuración ni registros que contengan el Client ID, el Client Secret o tokens de autorización.

    Configurar la copia¶

    Antes de pulsar el botón de ejecución, revise estos campos.

    Campo u opción Uso operativo Recomendación
    Carpeta destino Define dónde se guardan los archivos .encriptado. Use una ruta con permisos de escritura y espacio suficiente. En una instalación nueva se propone C:\backup_teamleader.
    Retroceder días Permite recuperar cambios anteriores. Mantenga 0 si no necesita ampliar el rango.
    Backup rehacer completo Fuerza una copia completa desde cero. Úselo cuando quiera reconstruir la copia o descartar una ejecución incremental.
    Descargar ficheros adjuntos Activa la descarga de adjuntos si introduce la clave correspondiente. Verifique antes que dispone de la clave y espacio en disco.
    Exportación a Excel - carpeta destino Convierte los archivos cifrados a un formato legible. La implementación actual genera .json, aunque la interfaz use el nombre “Excel”. La confirmación solicita el Client Secret.

    Consulte Configurar las opciones de copia para decidir cuándo utilizar cada campo.

    Ejecutar y supervisar¶

    1. Pulse Ejecutar backup cuando la configuración esté lista.
    2. Observe la zona de consola o estado para comprobar el avance.
    3. Espere el mensaje de finalización antes de abrir o mover archivos generados.
    4. Use Detener solo si necesita cancelar. El botón solicita la cancelación; espere hasta que el estado indique Cancelado.

    No interrumpa los archivos

    No cierre la aplicación ni mueva la carpeta de destino mientras la copia está en curso. Una interrupción puede dejar una ejecución parcial.

    Comprobar el resultado¶

    Al terminar, verifique el resultado antes de dar la copia por válida.

    Evidencia Qué revisar Dónde mirarlo
    Estado final Que la ejecución haya terminado correctamente o indique una cancelación controlada. Etiqueta de estado o consola integrada.
    Archivos generados Que existan archivos .encriptado y que la fecha corresponda a la ejecución. Carpeta seleccionada en Carpeta destino.
    Adjuntos Que se hayan creado o actualizado los archivos esperados si activó la opción. Carpeta destino o subcarpetas generadas por la herramienta.
    Conversión legible Que existan archivos .json en la carpeta elegida. Carpeta indicada en el bloque de exportación.
    Registro y estado Que no haya mensajes de error y que el estado final sea coherente. Consola integrada y registro disponible en la instalación.

    Una carpeta con archivos no demuestra una copia correcta

    Compruebe también el estado final y las fechas. Si la ejecución terminó con errores o fue cancelada, trate el resultado como parcial.

    Checklist antes de usar Backup TL¶

    • Backup TL está instalado o extraído desde una versión concreta de GitHub Releases.
    • Las credenciales necesarias están disponibles y se introducen solo en la herramienta.
    • La carpeta destino existe, tiene permisos de escritura y suficiente espacio.
    • Se decidió si la copia será incremental o completa.
    • Se decidió si se descargarán adjuntos.
    • Se decidió si se convertirán los archivos a JSON.
    • Se revisará el estado final antes de cerrar la herramienta.
    • Se conservará el registro si la ejecución debe auditarse.

    Siguiente paso¶

    Si la copia básica terminó correctamente, revise las opciones de copia completa, días anteriores y adjuntos. Si apareció un error, vaya a Resolver problemas antes de repetir la ejecución.
